# 万象研习社 · 王者万象棋非官方学习站

## 部署
Railway production 的 football-wire 服务使用 Dockerfile，仅打包 server.js、start.sh、site/。
旧网站文件留在仓库历史中，不会打包到此站点；Postgres、Miniflux、RSSHub 与 LibreTranslate 未修改。
Node 22+，无需依赖安装。访问 /healthz 可检查服务存活。

## 数据
site/data.json 基于用户 2026-10-09 在 ChatGPT 中生成的《王者万象棋_阵容深度优化_v2.0.html》，含85英雄、20棋手研究摘要、14构筑、105天赋名称；附 2026-10-08 v1.5.1 公告已核实改动。
这不是游戏官方实时数据：卡面全文、技能数值、完整装备与效果卡、即时胜率仍有缺口，所有推荐均仅供学习，不等于官方游戏规则。
网站包含资料来源链接，未复制第三方无明确许可证仓库的代码或完整数据。

## 功能
图鉴多标签过滤；7位英雄构筑器；阵营禁入推演与启发式解释；策略知识课；10题随机训练与浏览器学习进度；复盘记录；官方版本改动速查。
浏览器本地 localStorage 保存学习数据；不提供跨设备同步。
