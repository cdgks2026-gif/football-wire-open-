# 向往田园 · 在线开源版

原创田园经营网页游戏。玩法方向包含种植、烹饪、合成、订单、探索、家园建设、NPC 好感和收藏等。

## 在线版特点

- iPhone / Android / 电脑浏览器适配
- 单页网页游戏
- 本地自动存档
- 金币、钻石、体力和基础物资固定为 9,999,999,999,999
- 等级、剧情、建筑、图鉴仍保留成长过程
- 无充值、无广告
- 写实田园摄影风 UI
- 公开源码，MIT License

## 本地运行

```bash
npm start
```

然后访问 `http://localhost:3000`。

## 说明

本项目为原创网页游戏，不包含第三方商业游戏的代码、角色、美术素材或付费绕过逻辑。玩法系统采用通用的模拟经营与合成机制自行实现。
